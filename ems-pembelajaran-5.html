📖 Materi Pembelajaran

Keselamatan kerja

Gunakan APD yang sesuai, pastikan area kerja aman, hindari sumber api di sekitar bahan bakar, dan ikuti prosedur manual servis.

Pemeriksaan visual

Periksa kondisi konektor, kabel, selang bahan bakar, selang udara, rumah filter, throttle body, dan komponen terkait.

Pemeriksaan sistem

Gunakan alat ukur/diagnostic tool sesuai prosedur dan spesifikasi pabrikan. Catat hasil pengukuran dan bandingkan dengan standar servis.

Dokumentasi

Foto kondisi sebelum/sesudah, catat hasil pemeriksaan, temuan, tindakan perbaikan, dan kesimpulan.

Catatan: Jenis dan susunan komponen dapat berbeda menurut model sepeda motor. Untuk pekerjaan servis, gunakan manual servis kendaraan yang digunakan sebagai unit praktik.

🔧 LKPD Praktik

Judul Kegiatan

Pemeriksaan dasar Engine Management System pada sepeda motor.

Tujuan Praktik

  1. Mengidentifikasi komponen EMS pada unit praktik.
  2. Memeriksa kondisi fisik konektor, kabel, saluran bahan bakar dan udara.
  3. Melakukan pengukuran sesuai prosedur dan spesifikasi manual servis.
  4. Mencatat hasil, menganalisis temuan, dan membuat kesimpulan.

Keselamatan Kerja

  • Gunakan APD yang sesuai.
  • Jauhkan sumber api dari bahan bakar.
  • Pastikan kendaraan aman sebelum pemeriksaan.
  • Ikuti manual servis dan instruksi guru.
