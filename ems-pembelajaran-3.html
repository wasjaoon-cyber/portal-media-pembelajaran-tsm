📖 Materi Pembelajaran

Sensor sebagai input

Sensor mengubah kondisi fisik/operasi menjadi sinyal listrik yang dapat diproses ECU/ECM. Jenis sensor dan jumlahnya berbeda menurut model sepeda motor.

ECU/ECM sebagai pengolah

ECU/ECM menerima input, menggunakan data tersebut bersama strategi kontrol dan parameter yang tersimpan, lalu menghasilkan perintah ke aktuator.

Aktuator sebagai output

Aktuator mengubah perintah listrik menjadi tindakan mekanis/hidraulis/elektris, misalnya penginjeksian bahan bakar atau pengendalian komponen tertentu.

Pemeriksaan dasar

Pemeriksaan harus mengikuti manual servis kendaraan: kondisi konektor, kabel, sumber tegangan, ground, kode kerusakan, dan pengukuran sesuai spesifikasi pabrikan.

Catatan: Jenis dan susunan komponen dapat berbeda menurut model sepeda motor. Untuk pekerjaan servis, gunakan manual servis kendaraan yang digunakan sebagai unit praktik.
