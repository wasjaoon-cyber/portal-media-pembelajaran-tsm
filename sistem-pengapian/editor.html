Upload Media Lokal



Media tidak dikirim ke internet. File disimpan pada browser komputer ini menggunakan IndexedDB. Untuk GitHub Pages, salin file media ke folder proyek agar siswa lain dapat melihatnya.

Media Tersimpan di Browser Ini

Cara memasukkan media ke GitHub

  1. Buat folder media/gambar dan media/video di proyek.
  2. Salin file gambar/video dari komputer ke folder tersebut.
  3. Untuk media publik, gunakan nama file sederhana, misalnya rangkaian-ac-cdi.jpg atau video-ac-cdi.mp4.
  4. Masukkan file melalui GitHub lalu hubungkan dari halaman materi.
Catatan: Browser tidak mengizinkan halaman web menyimpan path seperti C:\Users\... untuk dipakai siswa lain. Karena itu editor ini menggunakan penyimpanan lokal browser untuk kebutuhan guru, sedangkan media yang ingin tampil di GitHub harus ikut diunggah ke folder proyek.
